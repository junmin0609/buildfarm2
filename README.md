# BuildFarm

Godot 4.7로 만든 2D 픽셀 농장 게임의 기본 버전입니다. 16px 도트 그래픽을 4배로 확대해 보여줍니다.

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| 마우스 왼쪽 / Space | 손에 든 도구·씨앗 쓰기 (다 자란 작물은 수확). 0.5초에 한 번, 누르고 있으면 0.5초마다 계속 (`player.json`의 `tool_cooldown`) |
| E / 마우스 오른쪽 | 상호작용 (집: 잠자기, 가게: 들어가기, NPC: 말 걸기, 작물: 수확) |
| 1~9 / 마우스 휠 | 핫바 선택 |
| I / Tab | 가방 (칸을 끌어다 놓아 옮기기·합치기, 화면 아래 핫바와도) |
| B | 건설 창 (설치·옮기기·철거) |
| Esc | 메뉴 (계속하기·저장하기·불러오기·새 게임). 창이 열려 있으면 창 닫기 |
| 도끼·곡괭이로 클릭 | 장애물 치우기 (개간) |
| Esc | 창 닫기 |

목표 칸은 마우스가 플레이어 주변 2칸 안에 있으면 그 칸, 아니면 바라보는 방향 바로 앞 칸입니다 (`data/player.json`의 `reach_tiles`).
작물 위에 마우스를 올리면 커서 옆에 정보(자란 날·오늘 물·수확까지 남은 날)가 뜹니다. 괭이·곡괭이로 자라는 작물을 치면 뽑힙니다(씨앗은 돌아오지 않음).

## 게임 규칙
- 괭이로 농장 땅을 갈고 → 씨앗을 심고 → 물을 주고 → 집에서 자면 다음 날 자랍니다.
- 물을 준 날만 하루씩 자랍니다. 매일 아침 물은 마릅니다.
- 물뿌리개는 물이 12번분 들어 있고(`items.json`의 `capacity`), 집 옆 **우물** 앞에서 [E]를 누르거나 물뿌리개로 우물을 클릭하면 최대 용량까지 찹니다. 개울·연못에서는 채워지지 않습니다.
- 하루는 실제 15분(시계 오전 7시 → 새벽 2시). 14분이 지나면 "1분 남았어요" 경고, 15분이 되면 하루가 끝나고 다음 날 오전 7시에 집 앞에서 시작(패널티 없음).
  상점·출하함·건설 창, 설치·옮기기·철거 중, 메뉴에서는 시간이 멈추고, 가방 창에서는 흐릅니다(가방이 열린 동안은 움직일 수 없음).
- 광장 **잡화점**에 들어가 주인에게 말을 걸어 씨앗·비료를 사고, 작물·가공품을 바로 팝니다(기준가의 80%). 시작 돈은 500G.
- 집 왼쪽 **출하함**에 넣어 두면 하루가 끝날 때 기준가 100%(품질 배율 적용)로 팔립니다. 그 전까지는 다시 꺼낼 수 있습니다.
  출하함 창을 열면 상점처럼 시간이 멈춥니다. 하루가 끝나면 그날 번 돈(출하함·광장 즉시 판매)을 **판매 수익 요약**으로 보여 줍니다(판 게 없으면 생략).

## 날짜 / 계절 (BUILD_FARM_PLAN §30, §34, §12)
- 봄 → 여름 → 가을 → 겨울 → 봄, 계절마다 28일 (`data/calendar.json`). 날짜 표시: "봄 3일 (수)", 2년차부터 "2년차 봄 3일"
- 작물은 씨앗의 `seasons`에 있는 계절에만 살 수 있다. 계절이 바뀌면 맞지 않는 작물은 **시든다**
  (자라지 않음·거둘 수 없음·물로 살아나지 않음, 괭이·곡괭이로 뽑아야 함, 비료 효과 끝). 여러 계절 작물은 다음 계절도 허용되면 그대로
- 계절이 바뀔 때 비어 있고 마른 밭은 35% 확률로 보통 땅이 된다 (젖은 빈 밭은 유지). "젖은"은 전날 물을 받았는지로 판단
- 겨울에는 바깥 밭에 씨앗을 심을 수 없다 (온실에서만)
- 씨앗 상점은 그 계절 작물 씨앗만 판다. 겨울에는 겨울 작물(시금치·브로콜리·사탕무, 온실 전용) 씨앗
- 코드: `scripts/time/calendar.gd`(`Calendar`), 하루 마감의 `season` 단계 → `FarmGrid.change_season()`

## 온실 + 겨울 작물 (BUILD_FARM_PLAN §35, §40)
- 건설 창(B)에서 짓는 8x7 건물. **3000 G + 나무 100 + 돌 100** (임시 값, `data/placeables.json`). 회전 없음
- 바깥 한 줄은 유리벽(지나갈 수 없음), 앞벽 가운데 2칸이 문. **안쪽 6x5 = 30칸이 온실 밭** (지붕 없이 그려서 안이 보임)
- 온실 밭: 맵 글자와 상관없이 괭이로 갈 수 있고, **어느 계절이든 어떤 작물이든** 심는다. 계절이 바뀌어도 시들지 않고 빈 밭도 되돌아가지 않는다
- 날씨 영향 없음: 비가 와도 젖지 않아 물뿌리개로 물을 줘야 한다
- 안에 작물이 있으면 옮기기·철거 불가 (아이템 보호 §105). 철거하면 돈·재료를 모두 돌려받고 안쪽 밭은 보통 땅
- 겨울 작물 (임시 수치): 시금치 4일 / 30 G → 55 G, 브로콜리 7일·3일마다 / 80 G → 45 G, 사탕무 8일 / 90 G → 160 G. 툴팁에 "겨울 (온실 전용)"
- 코드: `scripts/farm/greenhouse.gd`(`Greenhouse`), `FarmGrid.indoor_cells` / `is_indoor()`. 벽 그림은 뒷벽·옆벽·앞벽 4조각으로 잘라 Y 정렬(플레이어가 벽 앞뒤로 자연스럽게 가려짐)

## 날씨 (BUILD_FARM_PLAN §32, §33, §16, §100)
- 맑음·흐림·비, 겨울에는 비 대신 눈. 아침 07:00에 그날 날씨를 정하고 하루 동안 바꾸지 않음. 예보 없음
- **비**: 07:00부터 바깥 밭이 모두 젖어 있고(작물 성장 조건 충족), 그날 새로 간 밭도 젖음
- **눈**: 기획서상 비만 밭을 적시므로 날씨 상태·화면 효과로만 처리 (겨울은 바깥 농사 없음)
- 계절별 확률은 `data/weather.json` (임시 값). 여름은 초반·장마(10~19일)·후반 구간으로 나눠 장마에 비가 몰림
- 화면: 날짜 옆에 날씨 이름, 비·눈 효과(`WeatherOverlay`), 흐림·비·눈은 화면 색이 조금 바뀜
- 코드: `scripts/time/weather.gd`(`Weather`), 하루 마감의 `weather` 단계, 지금 날씨는 `GameState.weather` (저장됨)

## 퇴비통 (BUILD_FARM_PLAN §28)
- 건설 창(B)에서 짓는 2x1 시설. **200 G + 나무 30** (임시 값). 앞에서 [E] → 퇴비통 창 (출하함처럼 시간 정지)
- 재료와 점수 (`data/placeables.json`의 `compost.inputs`): 식물 섬유 1점, 밀·감자·당근 2점 (값싼 작물, 품질 상관없음)
- **10점**이 모이면 바로 한 번 분량을 떼어 익히기 시작 → 하루 마감(farm_daily 단계)마다 하루씩 → **3일** 뒤 **기본 비료 1개**가 퇴비통 안에 쌓임
- 익히기 전 "넣어 둔 재료"는 다시 꺼낼 수 있음 (최대 50점). 익히는 중인 분량은 꺼낼 수 없음
- 결과물은 플레이어가 직접 꺼냄. 가방에 들어가는 만큼만 꺼내고 나머지는 그대로. 결과물이 30개(한도)면 다 익은 퇴비는 기다렸다가 꺼내는 즉시 채워짐 (아무것도 사라지지 않음)
- 결과물이 있으면 퇴비통 위에 비료 아이콘이 뜸. 하루 마감 결과 `report.compost` = 그날 밤 만든 개수
- 옮겨도 내용물·진행 그대로. 철거하면 넣어 둔 재료·익히던 재료·결과물·건설비를 모두 돌려받고, 가방에 자리가 없으면 철거를 막음 (§106)
- 저장: 넣어 둔 재료·익히는 재료·진행 일수·결과물 (`build` 섹션의 시설 `state`)
- 코드: `scripts/farm/compost_bin.gd`(`CompostBin`), `scripts/ui/compost_bin_panel.gd`. 자동 투입은 나중에 `deposit` / `take_output`을 부르면 됨

## 창고 (BUILD_FARM_PLAN §67, §68)
- 건설 창(B)에서 짓는 4x4 시설. **1500 G + 나무 80 + 돌 40** (임시 값). 앞에서 [E] → 창고 창 (출하함처럼 시간 정지)
- 가방과 같은 칸 형식 (같은 아이템·품질끼리 쌓임, 물뿌리개는 남은 물 그대로 보관). 창고끼리 합쳐지지 않고 창고마다 따로 보관
- 창: 위 창고 칸 / 아래 가방 칸. **클릭 = 한 묶음, 우클릭 = 1개** 옮기기. [가방 물건 모두 넣기]는 핫바(맨 윗줄)를 뺀 가방 칸을 넣음
- 칸 수와 증축 (`data/placeables.json`의 `storage.levels`, 임시 값): 36칸 → 54칸(1000 G + 나무 60 + 돌 60) → 72칸(2500 G + 나무 120 + 돌 120). 마지막 단계가 한도
- 필터(받을 물건): 전체 / 작물만 / 씨앗만 / 재료만 / 가공품만(가공기가 생기면) / 지정 아이템(최대 9개, [가방에서 고르기] → 가방 칸 클릭, 아이콘 누르면 빼기). 받지 않는 가방 물건은 흐리게 보임
- 필터는 넣을 때만 봄. 필터를 바꿔도 이미 든 물건은 그대로, 꺼낼 수 있음. 칸이 차면 들어가는 만큼만 넣고 나머지는 가방에
- 옮겨도 내용물·단계·필터 그대로. 철거하면 안의 물건 + 건설비 + **증축 비용**까지 모두 돌려받고, 가방에 자리가 없으면 철거를 막음 (§64, §106)
- 저장: 단계·필터·칸 (`build` 섹션의 시설 `state`)
- 코드: `scripts/factory/warehouse.gd`(`Warehouse`), `scripts/ui/warehouse_panel.gd`. 컨베이어·자동 수확기는 나중에 `insert(아이템, 개수, 품질)`을 부르면 됨 (필터 지킴, 못 넣은 개수 돌려줌)

## 가공기 + 레시피 (BUILD_FARM_PLAN §70~§74)
- 가공기는 두 종류 (사용자 결정): **수동 가공기**(전기 없음, 플레이어가 정한 횟수만 돌고 멈춤) / **전기 가공기**(완전 자동, 전력 사용 — 아래)
- 수동 가공기: 건설 창(B)에서 짓는 2x2 시설. **800 G + 나무 50 + 돌 30** (임시 값). 앞에서 [E] → 가공기 창 (시간 정지)
- 창: 레시피 고르기 → 횟수(−/+/최대) → [가공 시작]. 정한 횟수만큼의 재료를 가방에서 한꺼번에 가져감
  - 재료 품질 사용 순서: 낮은 품질부터(기본) / 높은 품질부터. **결과물 품질 = 그 회차 재료 품질의 평균** (`Quality.average`, 반올림)
  - 게임 시계가 흐르는 동안 진행 (`Events.time_advanced`). 창·상점·건설로 시계가 멈추면 같이 멈춤
  - 하루가 끝나면 진행 중인 1회분은 밤사이 완성 (`report.processed`), 나머지 회차는 다음 날 이어서
  - 결과물은 가공기 안에 쌓이고 직접 꺼냄 (최대 30개, 가득 차면 다음 완성은 대기). 정한 횟수가 끝나면 재료가 있어도 다시 돌지 않음
  - [취소]: 아직 안 만든 회차의 재료를 모두 돌려받음 (가방 자리가 없으면 취소 불가)
- 레시피 (`data/recipes.json`, §73 중 지금 작물로 만들 수 있는 20개): 처음부터 아는 기초 6개 = 밀가루·반죽·빵·설탕·토마토 퓌레·감자 과자. 나머지는 "잠김" (레시피 상점에서 배울 예정, `RecipeDB.learn` → `GameState.unlocks["recipe:<id>"]`에 영구 저장)
- 가공품 19종 (`items.json`의 `kind: processed`, 품질 있음, 출하함·광장에서 판매). **가격·시간은 임시 값**
- 옮겨도 진행 그대로. 철거하면 남은 재료·결과물·건설비를 모두 돌려받고, 가방에 자리가 없으면 철거를 막음
- 코드: `scripts/factory/processor.gd`(`Processor`, 설정은 `placeables.json`의 `processor`: tier·automatic·max_runs·max_output·power), `scripts/factory/recipe_db.gd`(`RecipeDB`), `scripts/ui/processor_panel.gd`

## 중급 가공기 + 2급 레시피 (BUILD_FARM_PLAN §70, §73)
- **중급 가공기** (기계상점 6,000 G + 나무 80 + 돌 120, 3x3): 전기 가공기처럼 자동, 레시피 시간 ÷ 2 (`processor.speed`), 재료 4회분, 결과물 60개, 전기 시간당 70, 1·2급 레시피
- **2급 레시피** (레시피 상점에서 배움): 양배추 절임(양배추 2), 채소 절임 세트(양배추 절임 + 가지 + 무), 고급잼(과일 시럽 2 + **골드** 딸기 또는 블루베리 1)
- 레시피 재료 품질 조건: `recipes.json` 의 `"quality": {"strawberry": "gold"}` — 가방·창고·벨트 입구 모두 그 품질만 씀
- 봄 작물 **양배추** (5일, 한 번 수확, 씨앗 50 G · 75 G)
- 전기 가공기·수동 가공기 창에서 2급 레시피는 '중급 가공기가 필요해요'로 잠김. 수치는 모두 임시

## 전기 가공기 + 연료 발전기 + 지역 전기 통 (BUILD_FARM_PLAN §70, §75~§77, §97)
- **소형 발전기** 2x2 (**1200 G + 나무 40 + 돌 60**, 임시 값): [E] → 연료(식물 섬유 1개 = 20분, 나무 1개 = 1시간)를 넣으면 타는 동안 시간당 전기 **60**을 만들어 자기 전기 통(**300**)에 채움. 통이 가득 차면 쉬며 연료를 아낌. 안 탄 연료는 다시 꺼낼 수 있음
- **지역 전기 통** = 그 지역 발전기 통들의 합 (사용자 결정: 발전기들이 만든 전기를 모아 두고 기계들이 나눠 씀). 지역마다 따로, 전선 없음
- **전기 가공기** 3x3 (**2500 G + 나무 60 + 돌 80**, 임시 값): 레시피를 정하고 [자동 가공 켜기]
  - **맞닿은 창고**에서 1회분 재료를 가져와 만들고, 결과물도 맞닿은 창고에 넣음 (창고 필터 지킴). 넣을 곳이 없으면 가공기 안에 쌓고(최대 30개), 그것도 차면 멈춤
  - **실제로 만드는 동안에만** 지역 전기 통에서 시간당 **40**을 꺼내 씀 (사용자 결정). 통이 비면 멈췄다가 다시 차면 이어서
  - 레시피를 바꾸면 만들던 1회분 재료를 창고로 돌려놓음. 재료 품질 순서(낮은/높은 품질부터)는 창에서 고름
- 화면 오른쪽 위 시계 아래에 "전기 103 / 300" (지역 전기 통). 비면 빨간 "없음!". 발전기가 없으면 숨김
- 같은 시간에 만든 전기를 바로 쓸 수 있게 `BuildGrid`가 게임 시계(`Events.time_advanced`)를 받아 발전기 먼저, 나머지 시설 다음 순서로 `on_time`을 부름

## 컨베이어 + 입출력 포트 (BUILD_FARM_PLAN §54~§61, §64, §65)

  - 철거 모드에서 누른 채 끌면 지나간 컨베이어를 모두 철거 (§65). 벨트 위 물건도 가방으로 (자리가 없으면 철거 불가)

  - 창고 4x4: 입구 왼쪽 2번째 줄, 출구 오른쪽 3번째 줄. 입구는 받을 물건 필터를 지킴. 출구는 창고 창의 **내보낼 물건**(출구 필터, 기본 "안 내보냄")에 맞는 물건을 앞 칸부터 1개씩
  - 전기 가공기 3x3: 입구 왼쪽 가운데, 출구 오른쪽 가운데. 입구로는 지금 레시피의 재료만 재료마다 2회분까지 받아 두고(`processor.input_runs`), 맞닿은 창고보다 먼저 씀. 출구로 가공기 안 결과물을 내보냄
  - 소형 발전기 2x2: 입구 왼쪽 아래 (연료만). 퇴비통 2x1: 입구 왼쪽, 출구 오른쪽 (기본 비료)
  - 수동 가공기는 포트 없음 (플레이어가 직접 돌리는 기계)
  - 맞닿은 창고와 바로 주고받기(전기 가공기)는 그대로 (사용자 결정: 같이 씀)
  - 포트가 있는 정사각형 시설(창고·전기 가공기·발전기)은 이제 R 로 돌릴 수 있음 (그림은 그대로, 포트만 돎)
- 데이터: `placeables.json`의 `"ports": [{"type": "in"/"out", "cell": [x, y], "side": "left"/...}]` (회전 0 기준)
- 공통 훅: `Placeable.ports / accept_item / provide_item`. 새 시설은 포트를 적고 이 둘만 만들면 컨베이어와 이어짐
- 코드: `scripts/factory/conveyor.gd`(`Conveyor`, 칸 하나), `scripts/factory/conveyor_net.gd`(`ConveyorNet`, 지역 전체를 앞 벨트부터 한꺼번에 움직임, `BuildGrid.conveyors`), 끌어서 깔기는 `BuildMode.belt_path / place_belts`

## 하늘시장 + 비행선 정류장 + 하늘섬 (BUILD_FARM_PLAN §84~§90)
- **열기** (사용자 결정: 정류장 복구 뒤): 광장 남동쪽 **오래된 비행선 정류장** (4x3, 지도 글자 `A`) [E] → 복구 창. 돈 + 재료를 한 번에 납품 (임시: 8,000 G + 나무 150 + 돌 150 + 밀가루 10 + 토마토 퓌레 5. 기획서의 금속은 아직 없음) → `GameState.unlocks["sky_station"]`

  - 하늘섬은 농장 맵 오른쪽 바깥(칸 80, 6부터 14x9)에 따로 그림. 비행하면 플레이어를 옮기고 카메라 범위만 바꿈 (`FarmWorld.travel`, `SkyIsland`). 밭·건설·장애물 없음, 둘레는 보이지 않는 벽
  - 섬에서 하루가 끝나면 집 앞에서 깨어남. 섬에서 저장하면 섬에서 이어서
- **팔기** (§90): 섬의 하늘시장 가판대 [E] → 가방에 든 작물·가공품을 오늘 값으로 1개/모두 팔기. 판매 요약에 "하늘시장"
- **시세** (`data/sky_market.json`, `SkyMarket`):
  - 하루 처음 볼 때 한 번 정해지고 그날 고정, 저장됨 (`GameState.sky_market`). 다음 날 예보 없음 (§85)
  - 그날 값 = 기준가 × 분류 흐름 × 아이템 흔들림 (× 이벤트), 그다음 품질 배율. 배율 0.5~2.0

  - 이벤트(§88, 하루 12%): 하늘 음식 축제(과일 ×1.3, 채소 ×1.2) / 곡물 풍년(곡물 ×0.75) / 고급 음식 유행(가공품 ×1.35)
  - 창에 오늘의 소식·분류별 흐름(▲▼)·품목별 기준가 대비 표시
- 아직 없음: 원격 시세 단말기(§91), 원격 출하함(§92), 자동 판매(§93)

## 분배기 · 합류기 · 필터 분배기 (BUILD_FARM_PLAN §62)
- 셋 다 **1칸**, 컨베이어처럼 물건 1개를 잠깐 들고 있다가 넘김. 전기 없음. R 로 방향. 건설 창 "물류"
- 왼쪽·오른쪽은 **물건이 흐르는 방향 기준** (앞을 보고 선 사람의 왼손·오른손)
- **분배기** (사용자 결정: 3갈래): 뒤에서만 받아 왼쪽 → 앞 → 오른쪽 차례로. 벨트가 없거나 막힌 쪽은 건너뜀 (두 곳만 이어지면 반반)
- **합류기**: 뒤·왼쪽·오른쪽에서 받아 앞으로. 여러 쪽에서 기다리면 뒤 → 왼쪽 → 오른쪽 차례로 돌아가며 받음 (한쪽이 굶지 않음)
- **필터 분배기** (사용자 결정): [E] → 왼쪽(하늘색)·오른쪽(분홍) 출구마다 보낼 물건 (작물만/씨앗만/재료만/가공품만/지정 아이템). 맞는 쪽으로(둘 다 맞으면 번갈아), 안 맞으면 앞으로. 정한 쪽이 막히면 섞이지 않게 기다림
- 건설 모드에서 들어오는 쪽(초록)·나가는 쪽(주황) 화살표가 보임
- 값 (임시): 분배기·합류기 200 G + 나무 10 + 돌 5, 필터 분배기 500 G + 나무 10 + 돌 10
- 구조: `Router`(`scripts/factory/router.gd`)가 `Conveyor`를 상속. 연결 규칙 훅 `accepts_dir / can_take / exit_dirs / all_exit_dirs / on_sent`를 `ConveyorNet`이 씀 (벨트도 같은 훅). 창은 `scripts/ui/router_panel.gd`(`RouterPanel`). 그림 `make_routers` → `splitter_0~3.png` 등 (네 방향)

## 레시피 상점 (셰프, BUILD_FARM_PLAN §71)
- 광장 남서쪽 시설 터의 **레시피 상점** 3x2 (지도 글자 `C`) → [E] → 창 (상점처럼 게임·시간 멈춤)

  - 아직이면 이름이 "???"이고 얻어 본 재료만 이름이 보임 (예: "딸기 · ???")
- 창 순서: 배울 수 있는 것 → ??? → 배운 것(흐리게). 줄마다 재료·시간·결과물 판매가·값

## 아침 야간 생산 요약 (BUILD_FARM_PLAN §98)

## 하루 마감 (BUILD_FARM_PLAN §95~§102)
15분이 지나 강제로 끝나든(`time_up`) 집에서 자든(`sleep`) 똑같이 `GameState.request_day_end()` → `DayCycle.end_day()` 한 길로 갑니다.
처리 순서는 `scripts/time/day_cycle.gd`의 `PHASES` 한 곳에만 있습니다.

| 순서 | 단계 | 지금 하는 일 |
|---|---|---|
| 1 | `end_activities` | 열린 창(가방·상점·건설)과 건설 모드 닫기, 시간 정지·입력 잠금 풀기 |
| 2 | `settle_sales` | 출하함 판매(`ShippingBin.settle`), 오늘 장부(`GameState.today_sales`)를 `report.sales`로 → 판매 수익 요약 창 |
| 3 | `farm_daily` | 물 준 작물 성장·밭 마르기, 작은 장애물 재생 |
| 4 | `advance_date` | 날짜 +1, 시계 07:00 |
| 5 | `season` | 날짜가 새 계절로 넘어가면 작물 시듦·빈 마른 밭 되돌림 |
| 6 | `weather` | 오늘 날씨 결정, 비면 바깥 밭 전체 적시기 |
| 7 | `night_production` | (야간 생산 자리, 아직 없음) |
| 8 | `shop_refresh` | 오늘의 특별 상품 고르기 |
| 9 | `wake_up` | 집 앞(맵의 `@`)에서 아래를 보고 시작, 시설 아침 동작(`Placeable.on_day_started`) |
| 10 | `save` | (자동 저장 자리, 아직 없음) 날짜·07:00·집 시작 위치가 모두 반영된 뒤 맨 마지막 |

요약 화면(아직 없음)은 둘로 나눕니다: 하루를 끝낼 때 **판매 수익 요약**(오늘 번 돈, §99), 다음 날 아침 **야간 생산 요약**(밤새 생산된 결과, §98). 한 화면으로 합치지 않습니다.

끝나면 `Events.day_started(day)` → `Events.day_ended(report)`를 보냅니다.
새 시스템은 하루 끝 처리를 자기 파일에 흩지 말고 `world.day_cycle.add_step(DayCycle.NIGHT_PRODUCTION, func(report): ...)`처럼 단계에 등록합니다.
결과를 `report`에 적어 두면 아침 요약(§98, §99)에서 쓸 수 있습니다.

## 저장 / 불러오기 (BUILD_FARM_PLAN §102)

- 코드: `scripts/save/save_manager.gd`(`SaveManager`), 메뉴 `scripts/ui/system_menu.gd`

- 실버 ×1.25, 골드 ×1.6 (반올림). 황금호박·서리꽃 같은 특수 작물과 겨울(온실) 작물은 아직 없음
- **제철 씨앗만 심기**: 지금 계절이 씨앗의 `seasons`에 없으면 심을 수 없음 ("이 계절에는 심을 수 없어요"). 이미 심은 작물은 계절이 바뀔 때 시듦 규칙
- **씨앗 상점은 지금 계절에 심을 수 있는 씨앗만 진열** (여러 계절 작물은 해당 계절 모두, 겨울에는 씨앗 없음). 비료는 항상
- 그림: `tools/make_art.py`의 `CROPS`(잎 색)·`CROP_ART`(열매 높이·씨앗 봉지 색)·`produce()`. 새 작물은 줄을 뒤에 붙이고 `crop_row`·`icon`을 맞춘다

- 작물 수치는 `data/items.json` 씨앗 항목: `grow_days`, `regrow_days`(0 = 한 번 수확), `yield_min/max`, `seasons`(계절 시스템이 생기면 사용), `buy_price`. 작물 항목의 `sell_price`가 기준가(브론즈).
- **품질은 아이템을 나누지 않습니다.** `potato` 하나에 가방 칸마다 `quality`(`bronze`/`silver`/`gold`)가 붙고, 품질이 다르면 다른 칸에 쌓입니다. 도구·씨앗·재료는 품질 없음(`""`).
  가방 칸 형식: `{"id", "count", "quality"}` (+ 물뿌리개는 `"water"`). 창고·출하함도 같은 형식을 쓰면 됩니다.
  `Inventory.add/can_add/remove/count_of`에 품질을 넘길 수 있고, `count_of(id)`처럼 품질을 생략하면 모든 품질 합계입니다.
- 품질 배율·수확 확률은 `data/quality.json` (기획서 §25: 무비료 80/18/2, 기본 60/35/5, 고급 35/50/15, 최상급 15/45/40).

## 비료 (BUILD_FARM_PLAN §25~§27)
- 기본·고급·최상급 비료(`items.json`의 `kind: fertilizer`, `quality_table`), 씨앗 상점에서 수량 제한 없이 판매. **가격(50/120/250 G)은 임시 값**
- 괭이로 간 빈 밭에 **씨앗을 심기 전에** 뿌린다. 이미 비료가 있는 밭에는 덮어쓰지 않는다. 뿌리면 1개 사용
- 수확 품질은 그 밭 비료의 확률표로 뽑는다 (`SoilTile.quality_table()`)
- 한 번 거두는 작물은 수확하면 비료 효과가 끝나고, 다시 열리는 작물은 포기가 살아 있는 동안 유지. 작물을 뽑으면(앞으로 시들면) 끝 (`SoilTile.clear_crop()`)
- 비료를 준 밭에는 등급 색 알갱이가 보이고, 작물 정보에 "비료: ○○"가 나온다. 저장에 포함
- 판매가 = 기준가 × 품질 배율 × 판매 방식 배율 (`Pricing.unit_price`). 판매 방식 배율은 `data/economy.json`:
  광장 즉시 판매 `plaza` 0.8, 농장 출하함 `shipping_bin` 1.0. 하늘시장은 날마다 바뀌는 가격을 `Pricing.price_from`에 넘겨 쓰면 됩니다.
- 수확: 마우스 클릭(무엇을 들고 있든). 가방에 자리가 없으면 작물은 밭에 남습니다. 딸기는 거둔 뒤에도 포기가 남아 3일마다 다시 열립니다.

## 개간 시스템 (BUILD_FARM_PLAN §2, §46, §47, §103, §105)
시작 농장은 버려진 땅입니다. 집에서 가까운 순서로 바로 쓸 땅(약 30%) / 기본 도구로 치울 땅(약 50%) / 강화 도구가 필요한 땅(약 20%)으로 나뉩니다.

| 장애물 | 도구 | 등급 | 타격 | 자원 | 지나가기 |
|---|---|---|---|---|---|
| 잡초 | 괭이·도끼·곡괭이 | 1 | 1 | 식물 섬유 1 | 가능 |
| 나뭇가지 | 도끼 | 1 | 1 | 나무 1 | 가능 |
| 작은 돌 | 곡괭이 | 1 | 2 | 돌 1~2 | 막힘 |
| 그루터기 | 도끼 | 1 | 3 | 나무 2~3 | 막힘 |
| 큰 바위 | 곡괭이 | 2 | 6 | 돌 5~8 | 막힘 |
| 큰 그루터기 | 도끼 | 2 | 6 | 나무 5~8 | 막힘 |

- 도구 등급(`items.json`의 `tier`)이 모자라면 "더 좋은 곡괭이가 필요해요" 안내. 대장간 강화는 아직 없음 (등급 2 도구를 만들면 바로 동작).
- 가방에 자리가 없으면 장애물은 부서지지 않고 남습니다 (아이템이 사라지지 않음).
- 장애물이 있는 칸은 괭이질·건설 불가.
- 매일 아침 잡초·나뭇가지·작은 돌이 빈 농장 땅에 조금 다시 생깁니다. 밭·시설·장애물·플레이어 자리는 피하고, 큰 장애물은 다시 생기지 않습니다.
- 모든 수치(분포 비율·밀도·종류 가중치·타격 수·자원 개수·재생 확률)는 `data/obstacles.json`.
- 코드: `scripts/clearing/` (`ObstacleDef`, `ObstacleDB`, `Obstacle`, `ObstacleGrid`). 저장용 `to_data/load_data` 포함.

## 건설 시스템

- **R** → 시계 방향 90° 회전(설치·옮기기 중). 직사각형은 가로·세로가 바뀝니다(3x4 → 4x3). 정사각형 장식은 돌리지 않습니다.
- **집·출하함·우물**도 [옮기기]로 농장 땅 어디로든 옮길 수 있습니다 (철거는 안 됨, 처음 자리로 되돌리기 가능). 앞 한 줄은 늘 비워 둬야 하고(다른 시설·장애물 불가), 집을 옮기면 다음 아침부터 새 집 앞에서 깨어납니다. 출하함 내용물은 그대로 (`scripts/build/fixture.gd`)
- 같은 창의 **옮기기**(시설 클릭 → 새 자리 클릭, 무료) / **철거하기**(돈·재료 전액 환불, 기계는 기계 아이템으로 돌려받음)
- 돈으로 바로 짓는 건 허수아비·나무 창고·온실·퇴비통뿐. **공장·자동화 기계는 기계상점에서 아이템으로 사서** 가방에 있어야 놓을 수 있고(건설 창에 "가방에 N개"), 놓으면 가방에서 1개 빠짐
- 비용은 돈 + 재료(`"materials"`, 예: 온실). 기계는 `"price": 0, "materials": {"기계 id": 1}`. 재료가 모자라면 설치 불가, 철거 때 재료를 넣을 가방 자리가 없으면 철거 불가
- 설치 불가: 농장 땅이 아닌 곳, 다른 시설, 장애물(잡초·돌·나뭇가지·그루터기 등, 자동으로 치우지 않음), 작물이 자라는 밭, 플레이어가 서 있는 자리. 시설이 있는 칸은 괭이질도 안 됩니다.
- 갈아 둔 빈 밭 위에는 지을 수 있고, 지으면 그 칸은 보통 땅이 됩니다(§53). 철거해도 보통 땅으로 남습니다.
- 설치·옮기기·철거 모드인 동안은 시간이 멈춥니다.
- 마우스를 움직이면 마우스 칸, 키보드로 걸으면 플레이어 앞 칸 기준으로 놓입니다.

## 물 공급원 (우물 → 펌프 → 물탱크 → 자동 관개, §14)
물뿌리개는 `WateringCan.WATER_SOURCES`(`"water_sources"`) 그룹의 노드에서만 물을 채웁니다. 공급원은 세 함수만 있으면 됩니다.
- `covers_cell(cell) -> bool` 물뿌리개로 이 칸을 클릭하면 채우는가
- `provide_water(amount) -> int` 달라는 만큼 주고 실제로 준 양을 돌려줌 (우물은 무한, 물탱크는 남은 양만큼)
- `water_source_name() -> String` 안내 문구용 이름

지금은 `scripts/buildings/well.gd`(`Well`) 하나입니다. 펌프·물탱크를 설치 시설로 만들 때 `Placeable`을 상속한 스크립트에 이 세 함수를 넣고 그룹에 넣으면 물뿌리개가 그대로 씁니다.
